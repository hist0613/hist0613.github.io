강의 개요

파이썬으로 객체지향 프로그래밍의 핵심을 다룬다. 클래스와 객체에서 시작해 캡슐화, 특수메서드, 상속까지 쌓아 올리며, 개념마다 직접 코드를 짜고 실제 라이브러리가 같은 개념을 어떻게 쓰는지 읽는다.

학습 목표

  • 클래스와 객체를 설계하고 객체 간 협력을 코드로 표현한다
  • 캡슐화로 객체의 상태를 보호하고 검증한다
  • 특수메서드와 연산자 오버로딩으로 파이썬 문법을 클래스에 연결한다
  • 상속으로 공통 코드를 추출하고 계층을 설계한다
  • 객체가 메모리에서 어떻게 만들어지고 사라지는지 설명한다
강의 정보
  • 강의 시간: 수요일 4·5·6교시
  • 학점: 3학점
  • 선수과목: 컴퓨터프로그래밍기초 (파이썬 기본 문법)
사용 도구
  • 언어: Python 3.12 이상
  • 에디터: VS Code + Python 확장
  • 실행: 로컬에서 .py 파일을 터미널로 실행
  • 설치: 2주차에 안내. 각자 직접 설치해 온다
직접 짜보기

매주 개념 강의 뒤 라이브 코딩으로 함께 작성하고, 배포한 시작 파일에 그 자리에서 실습 과제를 이어 완성한다.

실제 코드 읽기

dataclasses, pathlib, scikit-learn, PyTorch가 같은 개념을 어떤 형태로 쓰는지 매주 읽는다.

내부 들여다보기

__dict__·__mro__ 같은 파이썬 자체 기능으로 문법 뒤에서 벌어지는 일을 확인한다.
