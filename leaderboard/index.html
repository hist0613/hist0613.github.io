How models are evaluated

  • Each model is evaluated with lm-evaluation-harness on vLLM, in bfloat16 with greedy decoding and the model's own chat template.
  • Reasoning records whether the chat template's thinking mode was on, and at which effort when the model supports it.
  • Benchmarks marked image come with images and are run only on models that take images, with every image scaled down to at most 2,048 pixels on the longer side. They are not part of the Average or Avg rank.
  • Eval time is the wall-clock time of one benchmark on the listed GPU, including model loading.
  • Output tokens are the generated tokens per item, counted with the model's own tokenizer and including any thinking text.
  • GPU memory is the model weights plus the KV cache for one 8,192-token request, as allocated by vLLM.
  • Only models that load with standard transformers architectures (no remote code) are evaluated automatically. Others are reviewed first.
